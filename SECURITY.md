## ⚖️ Legal Disclaimer & Operator Responsibility

Winux includes diagnostic, networking, and security auditing frameworks intended strictly for **authorized educational research, defensive system administration, and local forensic diagnostics**.

- **Authorized Systems Only**: You must only run security or diagnostic commands against systems, networks, or devices you legally own or have explicit, documented authorization to test.
- **Sole Operator Liability**: Any individual or organization executing these tools assumes **complete, sole, and exclusive responsibility** for all consequences, network traffic, actions, and legal liabilities.
- **No Maintainer Liability**: **TricksXTech**, its maintainers, and contributors assume **NO liability** and shall not be held accountable for any damages, service disruptions, data loss, or unlawful activities committed by third parties using this software.

## Reporting a Vulnerability

The Winux maintainers take code integrity and security very seriously.

If you discover a security vulnerability, bug, or security risk within the Winux codebase:

1. **Do not open a public issue.**
2. Send an email directly to the maintainers at **tricksxtech@gmail.com** or submit a [Private Vulnerability Report](https://github.com/TricksXTech/Winux/security/advisories/new) on GitHub.
3. Include detailed steps to reproduce the issue, the environment tested, and the expected behavior.

Reports will be reviewed within 48 hours, and security patches will be coordinated promptly.
