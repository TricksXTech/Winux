# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

The Winux maintainers take the security of this project very seriously.

If you discover a security vulnerability, bug, or risk within the Winux codebase:

1. **Do not create a public issue.**
2. Send an email to the project maintainers at **tricksxtech@gmail.com** or report via a [Private Vulnerability Report](https://github.com/TricksXTech/Winux/security/advisories/new) on GitHub.
3. Include detailed steps to reproduce the issue, the environment tested, and the expected behavior.

We will review reports within 48 hours and coordinate a public fix with attribution.
